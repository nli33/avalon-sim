# Avalon Sim

Self-evolving multi-agent simulation for [The Resistance: Avalon](https://en.wikipedia.org/wiki/The_Resistance_(game))

- Web dashboard for viewing games, including player POVs and omniscient-view
- Learned strategies that evolve via a reviewer agent that runs after games
